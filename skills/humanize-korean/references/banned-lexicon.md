# 금지 어휘 원장 (Banned Lexicon)

> SSOT. 2026-08-26 사용자 지시로 신설 — "AI 선호 단어 금지 원장을 만들고, 대체할 단어가 없는 경우를 제외하고 절대 쓰지 마라."
> 이 파일은 `quick-rules.md`(생성물)와 함께 전 경로 윤문 콜에 실린다. 밀도 조건이 없는 **단독 출현 금지** 규칙이다.

## 왜 원장이 따로 필요한가

L-1(포괄어 남용)은 "한 문장에 2개 이상 몰릴 때"라는 밀도 조건이 붙어 있었고 `_quick: false`라 런타임 룰북에서 빠져 있었다.
그 결과 "AI에게 일을 시키는 **자리**가 에디터에서 작업 공간으로 옮겨갑니다" 같은 단독 출현이 진단, 윤문, finalize 3콜을 모두 통과했다 (2026-08-26 실측, 사용자가 육안으로 잡아냄).
원장은 밀도를 세지 않는다. **보이면 바꾼다.**

## 규칙

1. 아래 표의 어휘는 쓰지 않는다. 초안에 있으면 대체 열의 후보로 바꾼다.
2. **예외는 넷뿐이다.**
   - 대체어를 넣으면 뜻이 달라지는 경우 (내용 앵커 훼손)
   - 외부 시스템, 제품, 기술의 고정 이름 (예: 계층형 저장소의 "층")
   - 직접 인용, 사용자가 직접 쓴 원문 문장
   - 관용 표현으로 굳어져 대체어가 어색해지는 경우 (예: "자리에 앉다")
3. 예외로 남긴 어휘는 `<!-- HUMANIZE-SUMMARY -->` 블록에 **어휘와 사유 한 줄**을 남긴다. 조용히 통과시키지 않는다.
4. 원장에 없는 어휘를 임의로 금지하지 않는다. 추가는 실측 근거와 함께 이 파일에 적는다.

## 표 1. 포괄 명사 (근거: `metrics_v2.py` `_VAGUE_NOUNS`, 사용자 27.7만자 대 에이전트 281.4만자 빈도 실측)

| 금지 | 대체 후보 |
|---|---|
| 자리 | 그것이 실제로 가리키는 이름 (도구, 화면, 역할, 단계, 순서, 위치) |
| 지점 | 단계, 시점, 조건, 줄, 호출부 |
| 층 | 겹, 단계, 계층 대신 실제 이름 |
| 상태 | 무엇이 어떤지 서술로 풀어 쓴다 |
| 대상 | 실제 대상의 이름 |
| 축 | 기준, 갈래, 구분 |
| 기제 | 방식, 장치, 구조 대신 실제 동작 서술 |
| 모양 | 형태 대신 무엇이 같은지 서술 |
| 측면 | 삭제하고 바로 서술 |
| 차원 | 삭제하거나 실제 범위 이름 |
| 셈 | 삭제 |

가장 흔한 사고는 **자리**다. "실력의 자리", "일을 시키는 자리", "그 자리에" 셋 다 지목 가능한 이름이 따로 있다.

## 표 2. 대동사 (근거: `metrics_v2.py` `_LIGHT_VERBS`)

| 금지 | 대체 후보 |
|---|---|
| 진행하다 | 실제 동작 동사 (돌리다, 열다, 맡기다, 고치다) |
| 실시하다 | 같음 |
| 수행하다 | 같음 |
| 실행하다 | 프로그램을 켜는 뜻일 때만 허용, 그 외 금지 |
| 이행하다 | 지키다, 따르다 |
| 전개하다 | 펴다, 벌이다, 넓히다 |

## 표 3. 과장, 관용구 (근거: taxonomy D-2, D-4)

| 금지 | 대체 후보 |
|---|---|
| 혁신적, 획기적, 압도적, 파격적, 폭발적, 전례 없는 | 구체 수치나 사실로 환원 |
| 시사하는 바가 크다, 주목할 만하다, 매우 중요하다 | 삭제하거나 무엇이 어떻게 중요한지 한 문장으로 |
| 핵심적인 역할을 한다 | 무엇을 하는지 동사로 |
| 새로운 지평, 판도를 바꾸다, 게임 체인저 | 삭제 |

## 표 4. 공식형 문틀 (근거: taxonomy D-1, D-6, D-7)

| 금지 | 대체 후보 |
|---|---|
| X에서 Y로, X을 넘어 Y로 | 직접 단언. 문서당 1회까지만 예외 |
| ~할 때입니다, ~시점입니다, ~할 순간입니다 | 구체 동사 단언 |
| 결론적으로, 이를 통해, 정리하자면, 요약하면 | 삭제 |
| 패러다임이 바뀐다, 자리가 옮겨간다, 무게중심이 이동한다 | 무엇이 어떻게 달라졌는지 서술 |

## 갱신 이력

- 2026-08-26 신설. 표 1과 표 2는 `metrics_v2.py`의 기존 실측 목록을 그대로 옮긴 것이고, 표 3과 표 4는 taxonomy D 계열에서 어휘만 뽑아 정리한 것이다. 새 어휘를 발명해 넣지 않았다.
