# 저자 불변성 — 계측기는 "AI"를 재는가 "클로드"를 재는가 (2026-08-25)

## 왜 쟀나

taxonomy 의 AI 티 신호는 전부 **클로드 출력**에서 관찰·검증됐다. 그러면 이 신호들이
"AI 글"을 재는지 "클로드 글"을 재는지 가를 수 없다. 후자라면 taxonomy 의 근거가
통째로 흔들린다.

이 질문은 **사람 코퍼스 없이** 답할 수 있다 — 다른 모델의 산문만 있으면 된다.

## 설계

같은 프롬프트 4종을 클로드와 코덱스에 각각 주고 8편을 받았다.

- 장르 2종: 검토물(A1·A2, 존댓말 판단 문서), 블로그(B1·B2, 해요체 에세이)
- 조건 동일: 900~1200자, 불릿·표 금지, 문단 산문만, 제목 없음
- 둘 다 **깨끗한 컨텍스트의 CLI 호출**(`claude -p` / `codex exec`)로 뽑았다.
  대화 세션에서 내가 직접 쓰면 taxonomy 를 아는 상태라 티가 억제돼 결과가 왜곡된다.
- 윤문 스킬은 태우지 않았다. 날것의 생성문이어야 티가 보인다.

프롬프트 원문은 `docs/validation_2026-08-25/prompts/`.

## 판정 셋

**1. 클로드 탐지기가 아니다 — 주 질문에 답이 나왔다.**
`vague_noun_rate` 가 85.11 대 86.30 으로 사실상 같다. 코덱스 산문에서도 같은 강도로
뜬다. taxonomy 의 근거는 이 축에서 무너지지 않는다.

**2. 그런데 쉼표 신호는 저자에 따라 갈린다.**
`comma_inclusion_rate` 가 코덱스에서 31% 높다(0.513 대 0.392). C-11 은 KatFishNet
AUC 94.88% 로 taxonomy 에서 가장 강한 신호인데, **그 강도가 저자에 따라 다르다.**
`hanja_nominalizer_density` 도 클로드는 4편 중 3편이 0.0 인데 코덱스는 3편에서 잡힌다.
임계 하나를 전 저자에 걸면 코덱스 글에는 엄하고 클로드 글에는 무른 검사가 된다.

**3. `light_verb_rate` 세 번째 사망.**
전수 코퍼스 0.0, 홀드아웃 AUC 0.500, 그리고 여기 8편도 전부 0.0. 세 번 다른 방법으로
쟀고 세 번 다 신호가 없다. **제거를 검토할 근거가 이제 충분하다.**

## 이 표를 과신하지 말 것 — n=4 다

`vague_noun_rate` 개별값이 0.0 에서 271.5 까지 흩어진다.

| | 검토물 | 블로그 |
|---|---|---|
| 클로드 | 0.0 / 0.0 | 170.2 / 271.5 |
| 코덱스 | 85.2 / 87.4 | 174.7 / 0.0 |

클로드는 **장르에 따라 0 과 271 을 오간다** — 저자 차이보다 장르 차이가 크다. 코덱스는
그 패턴이 안 보인다. 저자당 4편으로는 중앙값이 표본 하나에 흔들리므로, 위 판정 중
**1번(같다)은 비교적 안전하고 2번(다르다)은 더 재야 한다.** 같은 값이 우연히 같기는
어렵지만 다른 값이 우연히 다르기는 쉽다.

## 다음

- 2번을 확정하려면 저자당 표본을 늘린다(장르 4종 × 3샘플 = 저자당 12편)
- 장르별 `change_rate` 밴드는 이 8편에 윤문을 태우면 바로 나온다 — 아직 안 했다
- 사람 산문은 여전히 없다. 신호 뒤집힘(`nominal_dominance` AUC 0.275)은 이 실험으로
  풀리지 않는다 — 전문은 `validation_2026-08-25_word-precision-signals.md`
